📌 Project Overview

This project involves creating a responsive navigation menu using HTML and CSS. The menu is designed to adjust to different screen sizes, providing a smooth and user-friendly navigation experience on desktops, tablets, and mobile devices.

🎯 Objectives

* Create a navigation menu using HTML.
* Style the menu using CSS.
* Make the menu responsive for different screen sizes.
* Use Flexbox for alignment and layout.
* Apply hover effects to navigation links.

🛠️ Technologies Used

* HTML5 – To structure the navigation menu.
* CSS3 – To style the menu and make it responsive.

✨ Features

* Simple and clean navigation bar.
* Responsive layout for different devices.
* Navigation links with hover effects.
* Proper spacing and alignment.
* User-friendly design.

🚀 How to Run

1. Open the project folder in Visual Studio Code.
2. Open index.html using Live Server.
3. Resize the browser window to test the responsive layout.

📚 Learning Outcomes

Through this assignment, I learned how to create a navigation menu, use CSS Flexbox, apply media queries, and design responsive layouts for different screen sizes.
